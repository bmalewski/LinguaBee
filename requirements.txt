# PyTorch — WAŻNE: nie instaluj torch stąd bezpośrednio!
# Uruchom najpierw `python install_pytorch.py`, który wykrywa platformę i GPU
# (NVIDIA CUDA / AMD ROCm / Apple Silicon / CPU) i instaluje właściwy build:
#   - NVIDIA GPU   -> torch z download.pytorch.org (cu128)
#   - AMD GPU      -> torch ROCm z https://rocm.nightlies.amd.com/whl-multi-arch/
#                     (np. AMD Ryzen AI Max+ 395 / Radeon RDNA2-3.5 -> gfx target)
#   - Apple Silicon / CPU -> standardowe wheele PyTorch
# Dopiero potem uruchom `pip install -r requirements.txt` - torch będzie już
# zainstalowany z właściwym backendem, więc pip go nie nadpisze.
