# LinguaBee 0.9.3

## Krótki opis (do GitHub Release)

LinguaBee 0.9.3 poprawia czytelność i spójność interfejsu, wprowadzając ujednoliconą typografię Segoe UI oraz bardziej zbalansowane odstępy i proporcje kontrolek. Efekt to czystszy, bardziej zwarty układ i wygodniejsza praca przy codziennym użyciu aplikacji.

## Najważniejsze zmiany

- Ujednolicono font interfejsu na **Segoe UI** (wcześniej Calibri) w całej aplikacji.
- Poprawiono czytelność elementów UI:
  - dopracowane style etykiet i list rozwijanych,
  - zbalansowane rozmiary oraz odstępy checkboxów,
  - lepsza proporcja przycisków Start/Stop (wysokość i padding).
- Zmniejszono pionowe odstępy oraz marginesy w grupach ustawień, aby interfejs był bardziej zwarty i równy wizualnie.
- Ujednolicono minimalne wysokości wierszy w sekcjach:
  - Transkrypcja,
  - Tłumaczenie,
  - Streszczenie,
  - Formaty wyjściowe.
